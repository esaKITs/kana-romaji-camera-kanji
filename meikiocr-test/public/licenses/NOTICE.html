Corresponding source and rebuild

Exact application source, build scripts, dependency lock, model and asset locks, tests · MeikiOCR Web complete pinned source · ONNX Runtime source · MeikiOCR model-author source · Detector distribution · Recognizer distribution

Extract the application source, run npm ci, npm run build, npm test, then serve dist/ on HTTPS. Downloads are revision-pinned and hash-verified. No private keys, images from users, server services or paid APIs are needed.

Models: detector 14,503,825 bytes; recognizer 18,593,254 bytes; CPU WASM 14,239,897 bytes, glue 24,381 bytes. Horizontal printed Japanese only. The experimental engine and model/browser support must be verified on target hardware before production adoption.
