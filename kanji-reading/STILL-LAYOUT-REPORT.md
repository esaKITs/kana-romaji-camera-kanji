# Stillラベル配置の試作報告

2026年10月24日。対象は `development/kanji-reading` の研究用Still試作のみです。

## 実装

- 語ごとのラベルを、変換対象外の文字で区切った行内領域ごとにまとめ、空間を共有します。
- Canvasの実測文字幅を使い、通常幅、横圧縮（下限0.70）、2行の順で配置します。
- 1行のフォントは行高の0.56、2行ではその0.82（行高の約0.46）です。画面条件に応じた絶対的な最小px値はまだ決めていません。
- OCRの隣接文字枠が少し重なっていても、保存する文字の枠の外へ表示領域を切り詰めます。
- 元の語と横位置が重ならない配置、保存文字への衝突、ラベル同士の衝突は省略し、理由を記録します。
- 描画を表示矩形内にクリップします。色と白背景は従来の研究用描画を維持しています。第一弾の背景色判定との統合は未実施です。
- 2行分割は幅を均衡させる文字境界で行う試作です。音節・音韻境界は未考慮です。

## 再実行

`kanji-reading/lab` を作業ディレクトリとして、既存の `V2-README.md` の資産準備後に実行します。

```sh
npm test
npm run build:still
CHROMIUM_EXECUTABLE=/path/to/chromium node scripts/still-numeric-test.mjs
CHROMIUM_EXECUTABLE=/path/to/chromium node scripts/layout-browser-test.mjs
```

`results/numeric-still.json` はOCR再実行と描画結果、`results/layout-chromium.json` は同じOCRスナップショットの6条件再描画の結果です。後者はOCRを6回実行した結果ではありません。`results/still-numeric.png` に実際のCanvas出力を保存しました。
