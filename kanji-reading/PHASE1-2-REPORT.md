## 3. 第二弾アーキテクチャ案

OCRの全文・行・glyphを、かな抽出より前に受け取ります。次の共通処理を3モードで共有します。

1. **SourceDocument**：フレーム世代、原画像座標、行、全文、UTF-16 offsetとglyphの対応表を保持。縦書きは除外。無効座標を補造しません。
2. **RubyResolver**：本文とルビを位置・高さ・重なり・独立OCR一致で対応付け。確実なペアだけ本文読みを上書き。対応ルビは全モードで独立ラベルの対象から除外します。未確定ルビを本文に混入させません。
3. **ReadingWorker**：行の本文全文を形態素解析。surface/start/end/reading/POS/unknownを共通形式にします。かな・漢字を分断してから解析しません。
4. **ReadingDecision**：確認済みルビ ＞ 語・文脈・辞書の候補。未確定は原文を残します。辞書に載ることや2エンジンの一致だけを確信度とみなしません。
5. **ReadingAlignment**：語全体の読みと、漢字・かなの各source spanを別々に保持。食べる→食=た／べる=べる。熟字訓は漢字列全体で保持し、一文字ずつ割り当てません。複雑な交替は対応不能として保留します。
6. **ModeSelector**：「あア漢」は両かなと漢字、「ア漢」はカタカナと漢字、「漢」は漢字のみ。**残すかなも配置の障害物**として保持します。
7. **Romanizer**：既存変換を使用。読みと発音形を区別し、助詞のは/へ/をはPOSに応じて発音を選んでから既存処理へ。語境界での撥音・促音・長音の対応は統合時に検証します。
8. **LineAllocator / Renderer**：語と元文字位置の対応を保持し、行内の利用可能幅を配分。その後、既存の背景パレットと描画に渡します。

キャッシュは解析器・辞書version＋元の行全文をキーとし、試作では最大128件／1行4096 UTF-16単位に制限しました。モード・長音切替では再OCRしません。辞書はsingleton Workerで遅延読込し、切替や非表示時には破棄できる構造です。統合時にはフレーム世代が古い結果を破棄し、文書変更で位置履歴とルビ対応をリセットします。現在の試作はテキスト入力比較用で、Liveへは未統合です。

## 4. 比較条件と結果

対象は以下の**特定の配布物**です。解析器ファミリー全体の優劣や最新版同士の比較ではありません。

- `kuromoji@0.1.2`：JavaScript + 同梱IPADIC。
- `sudachi@0.1.5`：hata6502版Sudachi WASM。辞書がJS内に埋め込まれています。内包辞書の正確な版・edition・ソース対応は特定できていません。

30例の自作文章を全件入力しました。29例は読みの想定値、1例は未知漢字「龘」を未確定にできるかを確認します。助詞や全文の全トークンを総合採点した値ではなく、指定した語句の読みが想定値と完全一致した件数です。「明日＝アス」「日本語＝ニッポンゴ」は成立する読みなので、想定値との差をそのまま誤読とは呼びません。文脈依存例にも複数の解釈が成立し得ます。

| 実測項目 | Kuromoji 0.1.2 | Sudachi WASM 0.1.5 |
|---|---:|---:|
| 想定値完全一致（未知語保留1例を含む） | 21/30 | 23/30 |
| 配布サイズ | 辞書gzip合計 16.97 MiB + JS 301 KiB | 埋込JS 156.73 MiB（gzip参考 66.42 MiB） |
| 展開後辞書 | 95.62 MiB | 内包版の個別容量は未特定 |
| Node初期化 | 0.47 秒 | 7.08 秒 |
| Node RSS増分（OCRなし） | 347.9 MiB | 582.8 MiB |
| Node warm解析 p50 / p95 | 0.061 / 0.127 ms | 170.6 / 224.6 ms |
| Chromium初期化（ローカルHTTP） | 0.90 秒 | 6.17 秒 |


初期化時間は1回の起動例であり、安定した分布ではありません。Nodeのp50/p95はwarm状態の300回の文解析、ブラウザの時間はWorker内の解析・キャッシュ・整形込みです。初期化を含む最初の例をブラウザ分位値から除きました。ブラウザ初期化はローカルHTTP、ネットワークが速い開発環境です。実際のモバイル回線の初回起動とは異なります。

Node RSSは専用プロセスの初期化直後の増分であり、GCや一時バッファを含みます。ブラウザWorkerメモリ、iPhone Safariメモリ、OCRとの合算ではありません。最大RSS値には別途行ったファイル検査・gzip処理も含まれるため採用判断に使いません。

**一般的な形態素解析は、意味やコロケーションによる読み分けを全面的に保証しません。** 日付・数詞も別途発音の決定が必要です。漢字を1文字ずつ読ませる方式には進めません。

今回のSudachiパッケージでは、標準APIと異なり`dictionary_form`に「ヨミ」、`reading_form`に「読む」が返ります。初期化時に「読みました」の契約検査を行い、この版に限定して読みを抽出しました。将来の版やSudachiPyへこの補正を無条件に流用しません。

### 曖昧さの扱いの推奨

- 未知語・未取得の読み・読み対応不能な語は原文のままにします。
- 固有名詞、複数読みの既知語、数詞・日付は、ルビまたは検証済み規則がない限り確定表示を保留する案を勧めます。
- 今回の`reviewReason`は少数の既知語を保留対象にする実験で、網羅的な検出器ではありません。保留率と、表示した読みの誤り率を別々に測定する必要があります。
- 生物／人気のような誤りを、自作テストの正答に合わせた場当たり的置換で隠していません。比較表は解析器の素の出力です。

| NINJAL・NLB等 | 読み分けや共起の調査候補。公開辞書の利用条件とは別に各資料・検索系の契約を確認する |

KuromojiのコードはApache-2.0、同梱IPADICはNAIST/ICOTの通知条件を含みます。SudachiコードはApache-2.0で、今回のパッケージREADMEにはUniDic・NEologd由来データの通知があります。これらのファイルを`licenses/`へ保存しました。Kuromojiのブラウザ同梱コードにある圧縮・配列ライブラリの通知も保持対象です。lockfileで依存関係とintegrityを固定しています。

既存のMeikiOCR WebはGPL-3.0-only、モデルはLGPL-3.0、ONNX RuntimeはMITです。Apache-2.0の解析器を組み合わせる際にも、製品全体をMITだけと表示しません。GPL側の対応ソース、元の著作権・NOTICE・辞書条件を維持します。今回のライセンス調査は採用候補の確認であり、内包辞書の版やソース対応が不明なSudachi配布物を公開配布可能と判定したものではありません。

国語研の中納言は契約したうえでの用例検証に利用できる候補です。公開アプリへの生データ・共起表の組込みや再配布は別問題です。今回の試験文は自作で、コーパスのスクレイピング・用例転載・組込みはしていません。終了済みの梵天のページにも自動取得制限が記されていますが、その古い規約を現行の全サービスへ一般化していません。

ブラウザ内推定は、静的な解析器・辞書の取得後、外部の推論サーバーなしで実行できます。ただし、アプリ全体のオフライン起動・再読込・端末内キャッシュの永続性は別途実装・検証が必要です。今回「オフライン対応済み」とは報告しません。

## 6. 配置とUIの設計案（未実装・承認前）

### 配置

- 対象語だけでなく、残すかな、英数字、記号、隣接行も障害物にします。
- Canvasの`measureText`で通常幅を測り、語の原位置を含む行区間にラベルを置きます。前後の空白を、隣接語の対応範囲を侵さない範囲で配分します。
- 通常幅 → 前後空間の利用 → 横方向だけの圧縮 → 行間が許す場合の2行、の順序を守ります。
- 圧縮限界・最低可読サイズは実画像検証で決めます。収まらないものを極小文字や隣の本文の上へ押し込みません。
- 全文書のパレットを維持し、漢字ラベルの意味別色分けはしません。背景の白／暖色差とコントラストのための文字色処理を尊重します。
- Liveでは同じ語・行・フレーム登録をキーに直前配置を優先し、安定幅と位置の履歴を持ちます。文章変更時には古い配置を残しません。
- 3D表示や新しいポップアップは加えません。実画像の衝突・残す本文を覆わないかの検証はPhase 4です。

### UI案

第一弾の名称・ブランド・戻る・シャッター・Live/Still・Flash・Guide・長音切替を維持します。狭い画面で上段に全機能を詰め込まない案です。

| 領域 | 提案 |
|---|---|
| 最上段 | 戻る、アプリ名、esaKITs |
| その下の操作段 | 「あア漢／ア漢／漢」の3択。右端にaa／ā |
| カメラ内右上 | 既存のFlash／Guide操作 |
| 下中央 | Liveのシャッター、Stillの既存操作 |
| 表示説明 | 英語・アイコンを維持。新しい学習機能は追加しない |

これは承認用の情報配置案です。カメラ本体のUIは変更していません。比較labの「解析器選択」は研究用で、アプリに第4・第5モードを追加するものではありません。
