# v0.2.13 supplemental single-character detection

The canonical OCR core and its nine verbatim functions remain unchanged. An additive module, ppocr-single.mjs, detects single Japanese characters in source ink not covered by recognized canonical boxes. It does not guess characters from language context and never replaces canonical recognition.

New supplementary settings: luminance <160 and 8-connected ink components propose measured rectangles, filtered by the median canonical text height (height 0.4–1.8x, aspect 0.22–1.8). Each uncovered proposal gets a local crop with 0.8x median-height margin. The same neural detector runs at 3x crop scale with its original tensor, thresholds and boxesFromMap. Its boxes are mapped back to source pixels. Recognition uses the original vocabulary, CTC greedy decode, rotation and 48px height. Zero and 12% crop margins must yield the same single Japanese character with both minimum emitted scores >=0.85. These are model scores, not accuracy estimates. Body/ruby/held classification uses the original classifyLocal function; existing classifications are preserved.

The experiment adds an unchecked supplemental-detection checkbox. Camera Still and Live enable the same module. rawRegions/classifiedRegions always denote the canonical output; supplemental records all new decisions; extendedRegions and snapshot.lines add accepted measured regions. Full rawText includes supplemental text. Existing body and ruby are protected from replacement. No artificial character geometry or fixed image coordinates are used in production.

Practice A: canonical 66 raw / 63 classified regions remain identical to the archived original HTML. Four local proposals produce three accepted し regions and one rejected multi-character reading. All three shi become visible shi labels. Final rendering: 44 region labels, zero layout omissions (previously 41). Four original target words and ruby remain present. The actual browser test asserts enhanced-experiment / camera / synthetic-Live supplementary equality, canonical equality, three rendered shi, and Live-to-Still capture. Exact measured boxes and model scores are recorded in single-character-comparison.json and full traces in Actions artifacts.

This fixture does not establish universal recall or precision for every single character, font or photo. Low-contrast or disconnected ink may still be missed. Existing canonical results are preserved regardless of supplemental acceptance. Live retains the existing serialized frame processing and motion checks.
